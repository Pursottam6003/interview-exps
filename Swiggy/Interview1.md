Round 1:
interviewer Explained format (1/2 hr DSA, 1/2 hr Tech stack questions)

DSA: Number of Structurally Unique BSTs


SPRING BOOT INTERNALS

- What happens internally when we start a Spring Boot application?
- What happens inside SpringApplication.run()?
- How memory gets allocated
- What is the IoC container?
- What is ApplicationContext?
- How are beans created, stored and managed by Spring?
- How does Dependency Injection work internally?

REAL-WORLD PRODUCTION SCENARIOS

- Why does an application work in QA but fail in production?
- How would you investigate a production outage?
- What would you do if application latency suddenly increased?
- What happens when user traffic increases significantly?
- How would you identify whether the database is becoming a bottleneck?
- What happens when the database connection pool gets exhausted?
- How would you troubleshoot slow SQL queries?
- How would you introduce Redis caching?
- How would you scale the database?
- How would you communicate during a production incident?

REAL-WORLD SCALABILITY SCENARIO

We are taking a lot of time. Latency has increased. Earlier you had fewer users, but now you have more users, right? And the DB is choking off. So how, what will you do in this case?
